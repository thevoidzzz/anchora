## Tie out the trial balance
page: 2

The operator ties the trial balance to the subledger before sign-off. The tie-out code is TB-17.

## Book accruals
page: 4

Accrual JE-4419 is booked on the last business day of the period.

## Lock the period
page: 5

The period lock stops backdating after the tie-out is signed. The lock code is LOCK-3.

## Reopen a period
page: 6

Only the close lead reopens a locked period, and the reason is written in the reopen log.

## Bank reconciliation
page: 7

The bank statement is matched to the cash account line by line. The recon code is CASH-9.

## Inventory count
page: 8

The warehouse count is entered before the inventory account is closed. The count code is WH-4.

## Intercompany confirmation
page: 9

Intercompany balances are confirmed with the counterparty entity. The confirmation code is IC-22.

## Flux review
page: 10

A flux over the threshold is explained in the workbook. The flux code is FLUX-8.

## Controller sign-off
page: 11

The controller signs the close package after the checklist is complete. The sign-off code is SIGN-1.

## Payroll accrual
page: 12

Payroll earned through the cutoff is accrued. The payroll code is PAY-6.

## Fixed assets
page: 13

Assets placed in service this period are capitalized. The asset code is FA-11.

## Revenue cutoff
page: 14

Revenue is recognized only for shipments that left the dock. The cutoff code is REV-2.

## Tax pack
page: 15

The tax pack is filed with the return workpapers. The pack code is TAX-5.
